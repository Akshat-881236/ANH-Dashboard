# ANH-Dashboard

ANH-Dashboard is the centralized authentication, visit history, diagnostics, analytics, and user dashboard infrastructure for the Akshat Network Hub ecosystem.

## Features

- Google Authentication
- User Profile Management
- Visit History Tracking
- Diagnostics System
- Feedback Management
- SPA Dashboard
- Admin Analytics
- Firebase Integration

## Ecosystem Integration

Supports:
- AkshatNetworkHub
- Quizzone
- Portfolio-881236
- Key-of-Success
- LocalRepo

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Firebase
- Firestore
- Firebase Hosting

## Privacy Philosophy

ANH-Dashboard follows a transparent and privacy-responsible architecture aligned with existing Akshat Network Hub policies.
